# TV Kumanda

Xiaomi/Redmi IR blaster ile Samsung TV için yerel Android kumandası.

- Mi Remote benzeri kumanda arayüzü.
- IR test laboratuvarı: frekans, ham mark/space süreleri ve tekrar sayısı.
- Her tuşa ayrı komut eşleme; önce TEST ET, TV'de doğrulayınca KABUL ET.
- Kabul edilen komutlar cihazda saklanır.

Not: Telefonun ConsumerIrManager bileşeni IR vericisidir; TV'den sinyal dinleyemez. Otomatik öğrenme yerine kod/protokol denemesi yapılır.
